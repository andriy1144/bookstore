# BookStore (Курсовий навчальний проєкт)

Веб-сайт організації роботи книжкового магазину. Розроблено в рамках лабораторних робіт (ЛР 1.1 — ЛР 4.1) та курсової роботи з дисципліни «Технологія компонентного програмного забезпечення для веб».

## 🚀 Основні можливості
Застосунок є протестованим та оптимізованим Single Page Application (SPA):
- **Каталог:** 12 книг із JSON-джерела, пошук за назвою або автором, фільтр за жанром і наявністю (стан фільтрів зберігається в URL), згенеровані обкладинки (`BookCover`).
- **Маршрутизація (React Router):** параметризовані (`/books/:bookId`) і вкладені маршрути (`/orders`, `/orders/new`, `/orders/:orderId`, `/orders/:orderId/edit`), сторінка 404.
- **Асинхронний CRUD-цикл замовлень:** `async/await`, індикатори завантаження (`Spinner`), блокування повторного подання (`isSubmitting`), повтор запиту (`retry`).
- **Обліковий запис:** реєстрація, вхід, особистий кабінет з історією замовлень (`/register`, `/login`, `/profile`, `/logout`). Сесія зберігається як імітація JWT, маршрут `/profile` захищений компонентом `ProtectedRoute`.
- **Контакти:** сторінка `/contacts` з даними магазину та валідованою формою зворотного зв'язку.
- **Імітація API:** патерн «Адаптер» (`api.js` + `mockStorage.js` на базі `localStorage`), початкові дані описані у JSON-файлах `src/data/*.json`.
- **Оптимізація продуктивності:** розділення коду за маршрутами (`React.lazy` + `Suspense`), `useMemo`, `React.memo` (`BookCard`, `OrderRow`, `BookCover`) і `useCallback`.
- **Автоматизоване тестування:** Vitest та React Testing Library (модульні, компонентні та інтеграційні тести).

## 🛠 Технології
- React 19 + Vite 8
- React Router 8
- React Bootstrap 2 (Bootstrap 5)
- Тестування: Vitest, JSDOM, React Testing Library, user-event
- Контейнеризація: Docker

## ⚙️ Запуск проєкту

### Варіант 1: Нативний запуск (Node.js)
1. Встановіть залежності: `npm install`
2. Запустіть сервер розробки: `npm run dev`
3. Відкрийте браузер за посиланням `http://localhost:5173`

### Варіант 2: Запуск через Docker
1. Побудуйте та запустіть контейнер: `docker compose up --build`
2. Застосунок буде доступний за адресою `http://localhost:5173`

### Демонстраційний обліковий запис
Тестові дані з файлу `src/data/users.json`: пошта `demo@bookstore.test`, пароль `Bookstore2026`.

### Імітація мережевих збоїв
За замовчуванням імітаційний API працює без збоїв. Щоб перевірити стани помилок і повтору запиту, створіть файл `.env.local` з рядком `VITE_SIMULATED_FAILURE_RATE=0.1` (10 % запитів завершуватимуться помилкою 503).

## 🧪 Тестування та виробнича збірка
1. Запуск усіх автоматизованих тестів: `npm test`
2. Режим спостереження: `npm run test:watch`
3. Перевірка коду лінтером: `npm run lint`
4. Створення виробничої збірки: `npm run build` (результат у папці `dist/`)
5. Перевірка виробничої збірки локально: `npm run preview`
