# BookStore (Навчальний проєкт)

Веб-сайт організації роботи книжкового магазину. Розроблено в рамках лабораторних робіт з дисципліни "Технологія компонентного програмування для веб".

## 🚀 Нові можливості (Лабораторна 2.1)
Застосунок переведено на інтерактивну взаємодію з використанням React Hooks та Context API:
* **Керовані фільтри:** Миттєвий пошук книг за назвою та перемикач "Лише в наявності" (реалізовано через власний хук `useBookFilters`).
* **Глобальний вибір книги:** Клікнувши "Обрати" на картці, книга стає активною для замовлення (реалізовано через `BookSelectionProvider`).
* **Інтерактивне замовлення:** Керована форма чернетки з динамічним підрахунком загальної вартості (Total Price) залежно від кількості примірників.
* **Синхронізація ефектів:** Назва вкладки браузера (`document.title`) автоматично оновлюється при виборі книги.
* **UI/UX:** Інтерфейс повністю стилізований за допомогою React Bootstrap.

## 🛠 Технології
* React 18 + Vite
* React Bootstrap
* Контейнеризація: Docker

## ⚙️ Запуск проєкту

### Варіант 1: Нативний запуск (Node.js)
1. Встановіть залежності: `npm install`
2. Запустіть сервер розробки: `npm run dev`
3. Відкрийте браузер за посиланням `http://localhost:5173`

### Варіант 2: Запуск через Docker
1. Побудуйте та запустіть контейнер: `docker compose up --build`
2. Застосунок буде доступний за адресою `http://localhost:5173`

## 📦 Збірка для продакшену
Виконайте команду `npm run build`. Результат буде збережено у папку `dist/`.
