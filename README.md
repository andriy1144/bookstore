# BookStore (Навчальний проєкт)

Веб-сайт організації роботи книжкового магазину. Розроблено в рамках лабораторних робіт з дисципліни "Технологія компонентного програмування для веб".

## 🚀 Основні можливості (Поточний етап: Лабораторна 3.2)
Застосунок є повноцінним Single Page Application (SPA), що підтримує асинхронне опрацювання даних:
- **Маршрутизація (React Router):** Багатосторінкова навігація, параметризовані URL (`/books/:bookId`), вкладені маршрути (розділ замовлень) та обробка невідомих адрес (Сторінка 404).
- **Асинхронний CRUD-цикл:** Створення, перегляд, редагування та видалення замовлень за допомогою асинхронних функцій (`async/await`).
- **Імітація API та локальне збереження:** Використовується патерн "Адаптер" (`api.js`). Дані зберігаються у `localStorage`, а запити проходять через штучні мережеві затримки (Promise delays) для імітації реального бекенду.
- **Керовані форми та валідація:** Захист від введення некоректних даних (числові діапазони, залежні поля) із відображенням помилок та блокуванням подвійного надсилання форми (`isSubmitting`).
- **Керування станами (Context API):** Глобальний доступ до даних каталогу та замовлень, з інтегрованою обробкою станів завантаження (`isLoading`) і серверних помилок (`error`).
- **URL-фільтрація:** Збереження параметрів пошуку і сортування списків у адресному рядку (`useSearchParams`), що дозволяє копіювати посилання на відфільтровані результати.
- **UI/UX:** Інтерфейс повністю стилізований за допомогою React Bootstrap.

## 🛠 Технології
- React 18 + Vite
- React Router
- React Bootstrap
- API: імітація бекенду через `Promise` + `localStorage`
- Контейнеризація: Docker

## ⚙️ Запуск проєкту

### Варіант 1: Нативний запуск (Node.js)
1. Встановіть залежності: `npm install`
2. Запустіть сервер розробки: `npm run dev`
3. Відкрийте браузер за посиланням `http://localhost:5173`

### Варіант 2: Запуск через Docker
1. Побудуйте та запустіть контейнер: `docker compose up --build`
2. Застосунок буде доступний за адресою `http://localhost:5173`

## 📦 Збірка для продакшену
Виконайте команду `npm run build`. Результат буде збережено у папку `dist/`.
