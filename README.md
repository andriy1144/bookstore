# BookStore (Курсовий навчальний проєкт)

Веб-сайт організації роботи книжкового магазину. Розроблено в рамках лабораторних робіт (ЛР 1.1 — ЛР 4.1) з дисципліни "Технологія компонентного програмування для веб".

## 🚀 Основні можливості (Завершений застосунок — ЛР 4.1)
Застосунок є протестованим та оптимізованим Single Page Application (SPA):
- **Маршрутизація (React Router):** Багатосторінкова навігація, параметризовані URL (`/books/:bookId`), вкладені маршрути (`/orders`, `/orders/new`, `/orders/:orderId`, `/orders/:orderId/edit`) та сторінка 404.
- **Асинхронний CRUD-цикл:** Створення, перегляд, редагування та видалення замовлень через `async/await` з індикаторами завантаження (`Spinner`), блокуванням повторного подання (`isSubmitting`) і можливістю повтору запиту (`retry`).
- **Імітація API та локальне збереження:** Використовується патерн "Адаптер" (`api.js` + `mockStorage.js` на базі `localStorage`).
- **Оптимізація продуктивності:** Використано `useMemo` для відбору й сортування списків, `React.memo` для елементів списку (`BookCard`, `OrderRow`) та `useCallback` для стабілізації обробників подій.
- **Автоматизоване тестування:** Налаштовано Vitest та React Testing Library для модульного, компонентного та інтеграційного тестування.

## 🛠 Технології
- React 18 + Vite
- React Router
- React Bootstrap
- Тестування: Vitest, JSDOM, React Testing Library
- Контейнеризація: Docker

## ⚙️ Запуск проєкту

### Варіант 1: Нативний запуск (Node.js)
1. Встановіть залежності: `npm install`
2. Запустіть сервер розробки: `npm run dev`
3. Відкрийте браузер за посиланням `http://localhost:5173`

### Варіант 2: Запуск через Docker
1. Побудуйте та запустіть контейнер: `docker compose up --build`
2. Застосунок буде доступний за адресою `http://localhost:5173`

## 🧪 Тестування та виробнича збірка
1. Запуск усіх автоматизованих тестів: `npx vitest run`
2. Створення виробничої збірки: `npm run build` (результат у папці `dist/`)
3. Перевірка виробничої збірки локально: `npm run preview`
