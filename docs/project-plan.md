# План розробки веб-застосунку "BookStore" (Книжковий магазин)

## 1. Опис предметної області та проблематика
**Проблема:** Багато існуючих систем продажу книг є перевантаженими складним інтерфейсом, рекламою та заплутаною навігацією. Відсутній легкий, швидкий та інтуїтивно зрозумілий інструмент для перегляду технічної та художньої літератури з миттєвим доступом до оформлення замовлення.
**Рішення:** Розробка сучасного компонентного веб-застосунку (SPA) на базі ReactJS, який забезпечить миттєву фільтрацію каталогу, зручний перегляд деталей книги та максимально швидке оформлення замовлення без зайвих кроків.

## 2. Цільова аудиторія та користувачі
*   **Відвідувач / Покупець:** шукає необхідну книгу за жанром/автором, перевіряє наявність, ціну, додає товари до кошика та формує замовлення.
*   **Менеджер / Адміністратор (у перспективі):** керує каталогом товарів (додавання нових книг, зміна цін, оновлення статусу наявності) та обробляє запити користувачів.

## 3. Користувацькі сценарії (User Stories)
1. **Перегляд каталогу:** Користувач заходить на сайт, переглядає загальний перелік доступних книг у вигляді сітки карток.
2. **Пошук та фільтрація:** Користувач вводить назву або обирає жанр для швидкого знаходження потрібної книги.
3. **Оцінка наявності:** Користувач відразу бачить візуальний бейдж (статус), чи є книга в наявності, чи її статус "Очікується".
4. **Оформлення замовлення:** Користувач обирає книгу, переходить до форми оформлення, вказує кількість, свої контактні дані, адресу доставки та підтверджує створення заявки-замовлення.

## 4. Модель даних (Сутності)
*   **Книга (Book):**
    *   `id`: Унікальний ідентифікатор (рядок)
    *   `title`: Назва книги (рядок)
    *   `author`: Автор (рядок)
    *   `genre`: Жанр/Категорія (рядок)
    *   `price`: Вартість у гривнях (число)
    *   `available`: Статус наявності на складі (логічне значення)
    *   `description`: Анотація/опис (рядок)
*   **Замовлення / Чернетка заявки (OrderDraft):**
    *   `id`: Ідентифікатор замовлення
    *   `bookId`: Посилання на ідентифікатор книги
    *   `quantity`: Кількість примірників
    *   `deliveryAddress`: Адреса доставки

## 5. Структура сторінок (Route Map)
Поточний план розробки сторінок:
1. **Головна (`/`)** — Вітальний екран, опис платформи, переваги магазину.
2. **Каталог (`/books`)** — Загальний список карток книг із цінами та статусами.
3. **Деталі книги (`/books/:id`)** — Розширена інформація про конкретну книгу.
4. **Підготовка замовлення (`/order/new`)** — Форма для введення даних доставки та підтвердження покупки вибраної книги.
5. **Мої замовлення (`/orders`)** — Перелік сформованих заявок користувача (демонстраційні записи).

## 6. Технічний стек та архітектура
*   **Фронтенд:** ReactJS (з використанням функціональних компонентів та хуків).
*   **Збирач модулів:** Vite.
*   **Маршрутизація:** React Router (заплановано інтеграцію).
*   **Стилізація:** CSS Modules / чистий CSS (Grid/Flexbox).
*   **Контейнеризація та розгортання:** Docker (базовий образ Node.js для локального середовища розробки).
