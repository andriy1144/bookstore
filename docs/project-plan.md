# Книжковий магазин "BookStore"

**Проблема:** Відсутність зручного онлайн-каталогу для перегляду наявних книг та оформлення замовлень.
**Користувачі:** Відвідувачі (шукають і купують книги), Адміністратори (керують каталогом).

**Основний сценарій (Відвідувач):**
1. Відкриває застосунок і бачить головну сторінку з описом магазину.
2. Переходить до каталогу книг.
3. Переглядає назву, автора, жанр та статус наявності.
4. Знаходить потрібну книгу.

**Сутності:**
* Книга (id, title, author, genre, available, description)

**План сторінок:**
* Головна (`/`) — опис магазину.
* Каталог (`/books`) — перегляд списку книг.
* Деталі книги (`/books/:id`) — розширений опис.
* Кошик/Оформлення (`/cart`) — підготовка замовлення.
